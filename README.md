# Just For You — deploy on GitHub Pages
1. Create a GitHub repo, upload everything in this folder (keep the folder structure).
2. Settings → Pages → Deploy from branch → main / root.
3. Your link: https://YOUR-USERNAME.github.io/REPO-NAME/

Edit points are marked `EDIT` in index.html; colours/fonts at the top of css/style.css; timings at the top of js/script.js.
Swap images in assets/images/ (same filenames) and audio in assets/audio/i-choose-you.mp3.
Note: you need the rights/licence to publish the song.
